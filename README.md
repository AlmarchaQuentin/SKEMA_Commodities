# SKEMA_Commodities

This repository contains the work completed by our group for each of the assigned exercises.

## 1. EUA Positioning and Open Interest Sensitivity

Find the Commitment of Traders (COT) data for EUA positioning on Bloomberg. Analyse the sensitivity of EUA prices to changes in open interest.

## 2. Brent Options: Implied Volatility and Volatility Skew

Using an Excel file containing a portfolio of Brent call and put options, apply the Bachelier model to calculate implied volatility in dollar per barrel. Identify the polynomial function that best fits the implied volatility skew.

*Options: Minimum February 2027 maturity. Presentation scheduled for December.*

## 3. Modelling M1/M2 and M1/M3 Time Spreads Using Storage Fundamentals

Develop a model to explain and forecast M1/M2 or M1/M3 time spreads using storage data and other relevant technical or fundamental variables. Explore potential trading strategies based on the model's predictions.

## 4. WTI/Brent Spread: Physical Arbitrage Strategies

Using freight rates, export volumes, refinery runs, storage data, and WTI and Brent forward curves, develop a model to identify and capture trading opportunities in the WTI/Brent spread through physical arbitrage strategies.

## 5. Brent Volatility Risk Premium Strategy

Backtest a volatility risk premium strategy on Brent options by systematically selling options at different moneyness levels:

- ATM options
- 25-delta calls
- 15-delta calls
- 10-delta calls
- 25-delta puts
- 15-delta puts
- 10-delta puts

Evaluate the strategy's performance and risk characteristics across the different option positions.

## 6. Lead-Lag Regression: Crude Oil and Oil Products

Apply a lead-lag regression model (Levy Area) to investigate whether movements in individual oil products have predictive power for crude oil prices, and vice versa.

## 7. Power Generation Fuel Switching: Europe and UK

Develop a model to predict which fuel (natural gas, heating oil, or coal) is the most economically attractive for power generation.

Use Clean Spark Spreads (CSS) and Clean Dark Spreads (CDS) for both European and UK markets to identify fuel-switching opportunities.

## 8. Long-Term Spark Spread Option Pricing

Price a long-term option on the Spark Spread using Quasi-Monte Carlo simulation with the Sobol sequence method.

## 9. Japan Crude Cocktail: Proxy Hedging with Dated Brent

Develop a proxy-hedging model to support market-making activities in Japan Crude Cocktail (JCC), using Dated Brent as the hedging instrument.
